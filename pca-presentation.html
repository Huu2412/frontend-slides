The Problem

Why Do We Need PCA?

Real-world data lives in ridiculously high dimensions.

  • A 200×200 image → 40,000 features
  • Text with 50k vocab → 50,000 dimensions
  • Genomics data → 20,000+ genes

Goal: Find a function $f: \mathbb{R}^D \to \mathbb{R}^K$ where $K \ll D$
that preserves the "important stuff"

Core Intuition

The Big Idea: Find the Best "Viewpoint"

🖱️ Drag to rotate • Auto-rotates

Imagine data points floating in 3D space.

  • Data isn't random — it clusters along certain directions
  • PCA finds those directions (the principal components)
  • Then projects data onto them, dropping the "boring" axes

🎯 Think of it like this: Two cameras on a person — front view captures way more info than top-of-head view. PCA finds the "front view" of your data.

04 / 20
01
Step 1 & 2

Compute Mean & Center the Data

Step 1: Mean Vector

$$\bar{\mathbf{x}} = \frac{1}{N} \sum_{n=1}^{N} \mathbf{x}_n$$

Just the average of all data points across each dimension. Nothing fancy — literally np.mean(X, axis=1)

Step 2: Zero-Center

$$\hat{\mathbf{x}}_n = \mathbf{x}_n - \bar{\mathbf{x}}$$

Subtract the mean from every data point. This shifts the "center of mass" to the origin.

⚡ Why? Makes the math way cleaner. The covariance matrix simplifies beautifully when $\bar{\mathbf{x}} = \mathbf{0}$.

💻

X_centered = X - np.mean(X, axis=1, keepdims=True) # One line. Done.

05 / 20
02
Step 3

Build the Covariance Matrix

$$\mathbf{S} = \frac{1}{N} \hat{\mathbf{X}} \hat{\mathbf{X}}^T \in \mathbb{R}^{D \times D}$$

The covariance matrix tells you how features co-vary:

  • Diagonal entries $s_{ii}$ → variance of feature $i$ (spread)
  • Off-diagonal $s_{ij}$ → covariance between features $i$ and $j$
  • $s_{ij} > 0$ → features increase together
  • $s_{ij} = 0$ → features are uncorrelated

Properties of S

  • Symmetric: $\mathbf{S} = \mathbf{S}^T$
  • Positive semi-definite
  • Real eigenvalues $\geq 0$
  • Orthogonal eigenvectors

S = (1/N) * X_c @ X_c.T

06 / 20
03
Step 4

Eigendecomposition — Find the Magic Directions

$$\mathbf{S} \mathbf{u}_i = \lambda_i \mathbf{u}_i$$

where $\lambda_1 \geq \lambda_2 \geq \cdots \geq \lambda_D \geq 0$

  • Eigenvectors $\mathbf{u}_i$ → the principal directions
  • Eigenvalues $\lambda_i$ → variance captured by each direction
  • Bigger $\lambda$ = more important direction

🧠 Fun fact: The eigenvectors form an orthonormal basis — they're perpendicular and unit-length. PCA is basically a rotation of your coordinate system.

Steps 5–7

Pick Top-K & Project

Choose K Components

$$r_K = \frac{\sum_{i=1}^{K} \lambda_i}{\sum_{j=1}^{D} \lambda_j} \geq \text{threshold}$$

Pick the smallest $K$ such that $r_K \geq 0.95$ (or 0.99). This means you keep 95%+ of the variance.

📐 Common thresholds: 90% for speed, 95% balanced, 99% for accuracy

Project the Data

$$\mathbf{Z} = \mathbf{U}_K^T \hat{\mathbf{X}} \in \mathbb{R}^{K \times N}$$

$\mathbf{U}_K$ is the matrix with the top $K$ eigenvectors as columns. Multiply and done.

Reconstruct (Approx)

$$\mathbf{x} \approx \mathbf{U}_K \mathbf{z} + \bar{\mathbf{x}}$$

You can go back! (With some info loss)

08 / 20
Math Deep-Dive

What PCA Actually Optimizes

Minimize Reconstruction Error

$$J = \frac{1}{N} ||\mathbf{X} - \tilde{\mathbf{X}}||_F^2 = \sum_{i=K+1}^{D} \mathbf{u}_i^T \mathbf{S} \mathbf{u}_i$$

Equivalently: Maximize Retained Variance

$$F = \sum_{i=1}^{K} \mathbf{u}_i^T \mathbf{S} \mathbf{u}_i \quad \text{s.t.} \quad \mathbf{u}_i^T\mathbf{u}_j = \delta_{ij}$$

Total variance is invariant under rotation:

$$L = \text{trace}(\mathbf{S}) = \sum_{i=1}^{D} \lambda_i = \text{const}$$

Translation

Min error ↔ Max variance

$F = L - J$

Since $L$ is constant, minimizing $J$ = maximizing $F$

Solution: top-K eigenvectors of $\mathbf{S}$

Key Insight

PCA = Truncated SVD (basically)

SVD of Centered Data

$$\hat{\mathbf{X}} = \mathbf{U} \mathbf{\Sigma} \mathbf{V}^T$$

Truncated to rank $K$:

$$\hat{\mathbf{X}} \approx \mathbf{U}_K \mathbf{\Sigma}_K \mathbf{V}_K^T$$

Why this matters: In practice, just use np.linalg.svd() instead of computing the covariance matrix eigendecomposition. It's numerically more stable!

Hands-On Example

Eigenfaces — PCA on Face Images

Each 116×98 face image = 11,368-dim vector. PCA compresses them to ~100 dims.

# Yale Face Database: 15 people × 11 expressions
import numpy as np
from sklearn.decomposition import PCA

# X shape: (11368, 165) — each column is a face
pca = PCA(n_components=100)
Z = pca.fit_transform(X.T) # (165, 100)

# Reconstruct
X_approx = pca.inverse_transform(Z).T
print(f"Variance kept: {pca.explained_variance_ratio_.sum():.1%}")

40,000 → 100

dimensions reduced

Why It Works

  • Faces share structure (eyes, nose, mouth)
  • Eigenfaces capture these shared patterns
  • First few components = lighting & pose

🔬 Used in early facial recognition systems (Turk & Pentland, 1991)

Use Case

Anomaly Detection with PCA

Key idea: Normal data lives near the PCA subspace. Outliers don't.

Reconstruction error as anomaly score:
$$\text{score}(\mathbf{x}) = ||\mathbf{x} - \mathbf{U}_K \mathbf{U}_K^T \mathbf{x}||_2^2$$

# Anomaly detection pipeline
pca = PCA(n_components=K).fit(X_normal)

# For new data point x_new:
z = pca.transform(x_new.reshape(1,-1))
x_recon = pca.inverse_transform(z)
score = np.sum((x_new - x_recon)**2)

if score > threshold:
    print("🚨 ANOMALY DETECTED!")

Scaling Up

When Data Gets Huge — Power Method

Problem: With $D = 10^6$ and $N = 10^6$, computing the full covariance matrix is impossible.

Power Iteration

  1. Start with random unit vector $\mathbf{q}^{(0)}$
  2. Compute $\mathbf{z} = \mathbf{A}\mathbf{q}^{(k-1)}$
  3. Normalize: $\mathbf{q}^{(k)} = \mathbf{z} / ||\mathbf{z}||_2$
  4. Repeat until convergence
  5. $\mathbf{q}^{(k)}$ ≈ top eigenvector! 🎉

Fun fact: This is the core of Google PageRank!

Finding More Eigenvectors

$$\mathbf{B} = \mathbf{A} - \lambda_1 \mathbf{v}_1 \mathbf{v}_1^T$$

Deflate the matrix by removing the first eigenvector's contribution. Run Power Method again for $\lambda_2$. Repeat for K components.

When $D > N$ Trick

Instead of eigendecomp on $\mathbf{X}\mathbf{X}^T \in \mathbb{R}^{D \times D}$,
use $\mathbf{X}^T\mathbf{X} \in \mathbb{R}^{N \times N}$ (much smaller!)

If $\mathbf{X}^T\mathbf{X}\mathbf{u} = \lambda\mathbf{u}$, then $(\mathbf{X}\mathbf{X}^T)(\mathbf{X}\mathbf{u}) = \lambda(\mathbf{X}\mathbf{u})$

🔐 SOTA Connection #2

Federated PCA — Privacy-Preserving ML

The problem: you need PCA across data from multiple hospitals/banks, but can't share raw data.

How Federated PCA Works

  1. Each node computes local covariance $\mathbf{S}_i$
  2. Nodes send $\mathbf{S}_i$ (not raw data!) to the server
  3. Covariance is additive: $\mathbf{S}_{global} = \mathbf{S}_A + \mathbf{S}_B + \mathbf{S}_C$
  4. Server eigendecomposes $\mathbf{S}_{global}$ → distributes the eigenvectors

Raw data never leaves the local node — only a compact, additive statistic does.
